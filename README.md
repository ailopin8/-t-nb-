# ÀTÚNBÍ · Algorithmic Pattern Sandbox Network

The **10 × 10 × 10 cube is an environment**, not the algorithm or the pattern itself. An algorithm executes in each environment and evolves a spatial pattern. A pattern exposes a node output; a typed connection transforms its output into an input that modifies a pre-existing algorithm in another sandbox.

The initial working prototype uses two 1,000-cell environments and one measurable causal link. Source, tests, and a development plan will be committed from the deployed snapshot.

Live prototype: https://atunbi-algorithmic-sandbox-network-g8lqqr.v2.appdeploy.ai/
